# 认识团契的弟兄姊妹

一个无构建、无外部依赖的静态团契破冰活动页面。

## 使用

直接打开 `index.html` 即可运行。也可以把整个文件夹上传到 Netlify，或连接这个仓库后让 Netlify 直接发布根目录。

页面内容、题库、样式和逻辑都内嵌在 `index.html` 里。活动开始前先成功打开一次页面，之后即使网络断开，已经加载好的页面也可以继续添加人员、分组、翻卡、计时和计分。

## 数据

活动进度保存在当前浏览器的 `localStorage` 中，key 为：

```text
fellowship-jeopardy-state:v1
```

刷新页面会恢复人员、座位、队伍、分数和 Jeopardy 翻卡进度。换浏览器或换设备不会自动同步。

## 重置

页面右上角的“重置整场”会清空本机保存的活动数据，包括人员、座位、分组、分数和翻卡进度。
